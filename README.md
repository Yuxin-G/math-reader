## Project Motivation
Nowadays, AI becomes a significant role in helping people understanding content on a book. 

## Project Description
This project aims to build an AI assistant for reading books. You can select any contents from the pdf you are reading now and do the following

1. Ask a question for AI.
2. Speak out your feeling about the paragraph.
3. Obtain some exercises from AI for practicing a section.
